# Revisar contra la rúbrica

Leé `docs/01_REGLAMENTO_Y_RUBRICA.md` (checklist por criterio), `docs/ANALISIS.md` y el código.
Para cada criterio, marcá cada ítem del checklist como cumplido, parcial o faltante.

| Criterio | Puntos |
|---|---|
| Comprensión de la consigna | 10 |
| Procesamiento de datos | 25 |
| Funcionamiento integral | 25 |
| Calidad del código | 15 |
| Interfaz y usabilidad | 15 |
| Entrega y versionado | 10 |

## Salida

1. Puntaje estimado por criterio (honesto, sin inflarlo).
2. Lista de **máximo 7 mejoras** ordenadas por puntos ganados ÷ minutos necesarios, con el tiempo
   estimado de cada una. Solo cosas que se puedan terminar antes de las 16:00.
3. Riesgos que podrían hacer fallar la demo (por ejemplo, un cálculo sin probar) y cómo cubrirlos.

No hagas cambios de código en este paso: solo el informe.
